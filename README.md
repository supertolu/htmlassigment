# TBIL Property Website

This project is a simple static website built with HTML and CSS for a travel, property, and visa support landing page. It includes a homepage layout with navigation links and visual sections intended to promote services such as study abroad, flight booking, property listings, visa support, and contact information.

## Project Overview

The site is designed as a front-end assignment and focuses on:

- A branded homepage for TBIL Property
- Navigation links to related pages
- Responsive layout using CSS
- Image-based hero slider and branding elements
- Clean, static webpage structure for easy previewing

## Files

- `htmlassigment.html` — main homepage file
- `Assigment.html/` — additional assignment-related files and pages
- `images/` — image assets used by the website
- `style.css` files — styling for the pages

## Getting Started

Because this is a static HTML project, there is no build or installation step required.

### Option 1: Open directly in a browser

- Open `htmlassigment.html` in any browser.

### Option 2: Serve locally

From the project folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/htmlassigment.html
```

## Notes

- This project does not require a framework or package manager.
- The code is static and can be edited by updating the HTML and CSS files.
- Some links and file names appear to be case-sensitive in different environments, so it is a good idea to keep filenames consistent if you add or rename pages.
